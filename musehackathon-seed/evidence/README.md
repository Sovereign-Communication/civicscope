# Evidence — per-step landing rules

Each S-step lands its evidence here, in its own subdirectory
(`s2-…/`, `s3-…/`, …), only after that step's review unit completes.
Evidence is aggregate only: prompts, eval results, demo capture notes,
portal text drafts, and credit-budget accounting. Never keys, never
payment details, never raw query text where a slot shape exists (D5),
never chat transcripts, never other lanes' work.

A step's evidence is incomplete if it lacks: the step's prompt or
instruction, its test/eval results, its budget spend for the step, and
its manifest section. Live-tier evidence (S10), the S9 independent
run, S12 footage, and §8.5 real-user evidence land under their owning
steps — they are never implied by earlier steps' evidence.
