# Stewardship and ownership

The original request asks for a stewardship path that is genuinely nobody-owned.
This document exists because that claim has to be checkable rather than
asserted, and because writing it down is how a claim gets made checkable.

## The honest position

**This project has no owner and no funding.** Nobody is paid to work on it,
nobody can be contacted to request a change, and nobody benefits financially from
anyone using it. There is no advertising, no referral fee, no affiliate link, no
paid placement, and no code path that could accept money in exchange for a
ranking. That part of the claim is true and is enforced in code rather than by
promise — the completion gate fails the build if a protected-class metric enters
a composite score, and there is no payment integration anywhere in `src/`.

**Three things are not yet true, and are recorded here rather than glossed:**

1. **The canonical repository lives in a GitHub organisation.**
   `Sovereign-Communication/civicscope` is controlled by an organisation account,
   and an organisation *can* delete a repository. So the repository is not, in
   the strict sense, unowned. Anyone can fork it, but "anyone can fork" is not
   "nobody can take it away". The exit path is described below.

2. **The donation route reaches an individual, not a collective.**
   It is live, and it was live before this document was corrected — three direct
   routes (PayPal, Venmo, Cash App) in the funding section, reachable without a
   Census key. What changed here is the description, not the wiring. An earlier
   version of this file said there was no donation route and that one could not
   be created in code; both halves of that were wrong. The route can be three
   links, and the reason a collective was skipped is not that it is impossible
   but that it needs account setup and a fundraising decision first.

   The trade is real and is disclosed on the page rather than glossed: funds
   arriving at a person's accounts are personal property, the balance is not
   public, and if the project is abandoned the money stays with that person. A
   collective would have given the opposite three properties. The direct routes
   were chosen because they work immediately and need no incorporation.

   **The project has never received money and has never spent any.**

3. **No money means no continuity.** Nothing here is funded, so nothing is
   guaranteed. A source can vanish, a publisher can change an endpoint, and the
   maintainer may stop. This is stated plainly because a tool that presents
   itself as durable while resting on one unpaid person's spare time is
   misleading, regardless of how good its intentions are.

## What makes the data independent of all of this

The strongest stewardship property here is not organisational, it is technical:

**The product has no server.** There is no database, no account system, no
analytics, no search logging and no runtime backend. The whole tool is static
files on a CDN. The Census API key is the visitor's own, stored in their browser
and never sent anywhere.

That means nobody — including whoever runs the deployment — can:

- see who searched for what, or where they live
- return different results to different people
- be compelled by a court, advertiser, landlord or employer to change an answer
  for someone else
- sell, broker, rank or refer a listing, because there is no listing

An operator who cannot see a search cannot serve a different result to two
people who search the same ZIP code. That is a legal property, not a cost
saving, and it holds regardless of who owns the repository.

The same reasoning applies to verification. Every figure in this app can be
independently checked against the publisher's own API, and the app records the
dataset, table and variable behind each one. If a number here is wrong, you can
fetch the original and prove it.

## The exit path

Because the repository can be taken down, these are the specific things that make
the work survive that:

- **The data is public domain.** US Census Bureau output carries no
  restrictions. The map's geometry comes from TIGERweb and is regenerated by
  `npm run gen:map`, which is committed here and depends on no one.
- **Every number is reproducible from public endpoints.** The build fetches from
  publishers; it does not embed anyone's private data.
- **The deployment is reproducible from the repository.** A fork is a working
  copy of the whole product, including the baked map assets.
- **A fork can be deployed independently.** Nothing is gated on the canonical
  deployment, and no key is shared between instances.

If this repository were deleted tomorrow, the honest summary would be: the
source is lost, but every figure it showed remains obtainable from the US
Census Bureau, and the code that assembles those figures is short enough to
rewrite.

## What would make the claim stronger

In rough order of how much it would matter:

1. Move the repository to somewhere no single account can delete, or accept that
   an organisation is the owner and say so.
2. Move donations to a public collective, so the balance is visible and the money
   outlives the maintainer. This is the single change that would most improve the
   stewardship position, and it is now the only gap on this list that concerns
   money rather than ownership.
3. Record who holds the Cloudflare Pages account, and what happens to the
   deployment if they stop paying.
4. Publish a change-log or incident record, so that "verified" has a history
   rather than being a claim about the current state only.

Items 1 to 3 are decisions and accounts, not implementations, and pretending
otherwise would be the exact overclaiming this document exists to prevent. Item 4
is the one thing on this list that is genuinely just work.
